## Вариант А — Автоматическая сборка чистого `.apk` через бесплатное облако GitHub (за 2 минуты):
1. Войдите на https://github.com/new и создайте репозиторий (например, `fintrack-2026`).
2. Нажмите **uploading an existing file**, выделите все файлы и папки из этого архива (включая папку `.github`) и нажмите **Commit changes**.
3. Откройте вкладку **Actions** сверху -> дождитесь зелёной галочки напротив **Build Clean FinTrack 2026 APK** (около 1,5 мин) -> скачайте готовый **`FinTrack-2026-Clean-APK`**.
